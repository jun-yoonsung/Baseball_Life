# ⚾ 베이스볼 라이프 (Baseball Life)

**육성선수에서 명예의 전당까지** — 야구선수 한 명을 고교 졸업반부터 은퇴할 때까지 키우는 웹 커리어 시뮬레이션입니다.
가입·결제 없이 브라우저에서 바로 플레이하고, 은퇴한 선수는 일일 랭킹과 "오늘의 베스트 나인"에 자동 등록됩니다.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 선수 생성 | 국적 5개국, 시작 국가(한국·일본·미국), 타자 / 투수 / **이도류**, 수비 포지션 9개 + 선발·중계·마무리, 투타. 후보 3명(능력치 합계 270, 플레이 스타일·숨겨진 재능이 다름) |
| 능력치 | 타자: 컨택·파워·선구안·주루·수비·송구 / 투수: 구속·제구·구위·변화구·체력·멘탈. 포지션별 가중평균 오버롤. 숨은 잠재력·성장 유형·부상 체질·클러치·내구성 |
| 시뮬레이션 | 타석 단위 확률 모델 → 타율·OPS·홈런·도루 / 평균자책점(BaseRuns)·탈삼진·승·세이브·홀드 / wOBA 기반 WAR. 리그별 득점 환경(KBO 타고투저, NPB 투고타저, MLB 고삼진·고홈런) |
| 리그 | 실제 구단, 해마다 바뀌는 구단 전력, 전체 순위표, 실제 포스트시즌 방식(KBO 와일드카드~한국시리즈, NPB 클라이맥스 시리즈~일본시리즈, MLB 와일드카드 시리즈~월드시리즈) |
| 장비 | 배트·배팅 장갑·아대·스파이크·글러브·보호대·컨디셔닝·피칭 랩 장비 구매, 사용 기간 동안 능력치·부상·컨디션 보정, 용품 스폰서 |
| 진로 | 고졸 드래프트(라운드·순번·계약금), 대학 진학 4년, 미국 직행, 육성선수, 1·2군 및 마이너 싱글A~빅리그 오가기, 전·후반기 콜업과 강등 |
| 계약 | 연봉 협상, FA(8시즌/대졸 7시즌, 미국 6시즌), 재FA, 포스팅, 국내외 FA 제안 비교, 트레이드, 방출과 무적 생활, 에이전트 |
| 병역 | 국군체육부대(퓨처스에서 복무) / 현역 입대, 만 28세 자동 입대, 아시안게임 금메달·올림픽 메달 병역 특례(복무 중이면 조기 전역) |
| 국제대회 | 프리미어12, 2028 LA 올림픽, WBC, 아시안게임(만 25세 이하 우대), MLB 선수 차출 제한, 대회 MVP. 소집 시 합류 / 소속팀 집중(불참) / 국가대표 은퇴 선택 |
| 수상 | KBO MVP·신인상·골든글러브·수비상, NPB 리그별 MVP·베스트나인·골든글러브·사와무라상, MLB 리그별 MVP·사이영상·신인왕·실버슬러거·골드글러브·행크 애런상·구원투수상, 타이틀 13종, 시리즈 MVP, 올스타 |
| 이벤트 | 20여 종의 오프시즌 선택 이벤트(타격폼 수정, 신구종, 벌크업, 감독 갈등, 포지션·보직 전향, 이도류 도전, 광고, 결혼 등) |
| 부상 | 경상·중상·시즌 아웃, 토미존 수술 vs 재활(재손상 위험) |
| 노화·은퇴 | 성장 유형별 전성기, 30대 노화, 은퇴 권유, 명예의 전당 투표(1군 10시즌, 득표율 75%), 영구결번, 커리어 등급 |
| 랭킹 | 한국시간 기준 일일 랭킹(MVP → 최고 OVR → 개인상 → 통산 WAR, 동률 시 공동 순위), 최근 7일 조회, 오늘의 베스트 나인 |
| 저장 | 브라우저 자동 저장, 저장 파일 내보내기/가져오기, 시드 난수 저장(새로고침으로 결과 바꾸기 불가) |

KBO 10개 구단, NPB 센트럴·퍼시픽리그 12개 구단, MLB 아메리칸·내셔널리그 30개 구단(지구 포함)의 실제 구성을 씁니다. 개인 플레이용이며 공식 서비스가 아닙니다. 엠블럼은 로고가 아닌 약칭 글자입니다.

## 실행 방법

```bash
npm install

# 개발: 프런트엔드(5173) + 랭킹 API 서버(8787)
npm run dev:server   # 터미널 1
npm run dev          # 터미널 2 (/api 는 8787로 프록시)

# 테스트 / 타입 검사
npm test
npm run typecheck

# 배포: 빌드 후 서버 하나로 정적 파일 + API 제공
npm run build
PORT=8787 npm start
```

랭킹 서버에 연결할 수 없으면 게임은 그대로 동작하고, 랭킹 화면은 이 기기에서 은퇴한 선수만 보여 줍니다.
정적 호스팅(GitHub Pages 등)과 API 서버를 분리하려면 빌드할 때 `VITE_API_BASE=https://api.example.com`을 지정하세요.

### 서버 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `8787` | 포트 |
| `DATA_DIR` | `server/data` | 날짜별 랭킹 JSON 저장 위치 |
| `CORS_ORIGIN` | `*` | 허용 Origin |

## 구조

```
src/engine/     게임 엔진 (UI와 독립, 순수 TypeScript)
  types.ts        데이터 타입
  data.ts         리그·구단·득점 환경·포지션 가중치·수상 명칭·국제대회 일정
  league.ts       순위표, 포스트시즌 대진
  equipment.ts    장비 상점
  rng.ts          시드 난수 (mulberry32)
  ratings.ts      오버롤, 성장·노화
  sim.ts          타석 확률 모델, BaseRuns, WAR
  season.ts       시즌 진행(1·2군 배정, 부상, 올스타, 트레이드, 포스트시즌, 수상, 국제대회)
  career.ts       커리어 진행(드래프트, 오프시즌, 계약, FA, 포스팅, 병역, 은퇴)
  contracts.ts    연봉 시장가, 계약 제안
  events.ts       오프시즌 이벤트
  summary.ts      통산 기록, 명예의 전당
  ranking.ts      랭킹 정렬, 베스트 나인
  save.ts         저장/불러오기
  engine.test.ts  커리어 수십 개를 은퇴까지 돌리는 통합 테스트
src/pages/      화면 (홈, 선수 만들기, 커리어, 랭킹, 가이드, 소개, 설정)
server/index.mjs  의존성 없는 Node 랭킹 API + 정적 파일 서버
```
